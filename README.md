# مدیریت حساب 💰

برنامه حساب‌داری شخصی چندسکویی — یک کد، همه پلتفرم‌ها: **اندروید، ویندوز، مک، لینوکس و وب**

## ✨ امکانات

- **دسته‌بندی هزینه و درآمد** — کاملاً قابل ایجاد، ویرایش و حذف با رنگ و آیکون دلخواه
- **بدهکاران و طلبکاران** — ثبت بدهی برای هر شخص با:
  - عکس رسید/سند برای هر بدهی (چند عکس)
  - ثبت بازپرداخت مرحله‌ای با نوار پیشرفت
  - نمایش وضعیت کلی هر شخص (چقدر به من بدهکار است / من بدهکارم)
- **حساب‌های بانکی متعدد** — با موجودی اولیه، رنگ و یادداشت
- **ثبت خودکار از پیامک بانک** (اندروید):
  - با دریافت پیامک واریز/برداشت از شماره فرستنده تعریف‌شده، تراکنش خودکار ثبت می‌شود
  - حتی اگر برنامه بسته باشد، پیامک در صف ذخیره و در اجرای بعدی ثبت می‌شود
  - تبدیل اعداد فارسی/عربی و تشخیص کلیدواژه‌های «واریز، برداشت، خرید، پرداخت…»
  - امکان ثبت دستی با چسباندن متن پیامک (همه پلتفرم‌ها)
- **یادداشت تراکنش** — برای هر هزینه/درآمد بنویسید «این پول برای چه بود»
- **تاریخ شمسی** — نمایش و انتخاب تاریخ جلالی با اعداد فارسی
- **داشبورد** — موجودی کل، بدهی‌ها، هزینه ماه و نمودار دایره‌ای دسته‌بندی‌ها
- **پشتیبان‌گیری و انتقال** — خروجی یک فایل JSON (شامل عکس رسیدها) که روی هر دستگاه و هر پلتفرمی قابل بازگردانی است؛ فایل پشتیبان را با تلگرام/واتساپ/ایمیل بفرستید و در دستگاه دیگر وارد کنید
- **حالت تیره/روشن، واحد پول تومان/ریال، اعداد فارسی**

## 📥 دانلود نسخه نصبی

به بخش [**Releases**](../../releases) بروید و فایل مناسب دستگاه خود را دانلود کنید:

| فایل | پلتفرم |
|------|--------|
| `Modiriat-Hesab-Android.apk` | اندروید — نصب مستقیم (اجازه نصب از منابع ناشناس لازم است) |
| `Modiriat-Hesab-Windows-Setup.exe` | ویندوز — نصب‌کننده کامل |
| `Modiriat-Hesab-Windows-Portable.zip` | ویندوز — نسخه قابل حمل بدون نصب |
| `Modiriat-Hesab-Linux.deb` | لینوکس (Debian/Ubuntu) |
| `Modiriat-Hesab-Linux.tar.gz` | لینوکس — قابل حمل |
| `Modiriat-Hesab-macOS.zip` | مک (بعد از استخراج: راست‌کلیک → Open) |
| `Modiriat-Hesab-Web.zip` | وب — هر هاست استاتیکی |

هر push به مخزن، ساخت خودکار همه خروجی‌ها را در [Actions](../../actions) اجرا می‌کند.

## 🚀 ساخت از سورس

```bash
flutter pub get
flutter build apk --release          # اندروید
flutter build windows --release      # ویندوز
flutter build linux --release        # لینوکس
flutter build macos --release        # مک
flutter build web --release          # وب
```

## 📱 فعال‌سازی ثبت خودکار پیامک (اندروید)

1. به تب **حساب‌ها** بروید و حساب بانکی خود را اضافه کنید
2. **شماره فرستنده پیامک‌های بانک** را وارد کنید (مثلاً `98700077`) — چند شماره را با ویرگول جدا کنید
3. دکمه «مدیریت دسترسی پیامک» را بزنید و اجازه **SMS** را بدهید
4. از این به بعد هر پیامک واریز/برداشت آن شماره، خودکار در برنامه ثبت می‌شود

> نکته: چون برنامه خارج از گوگل‌پلی نصب می‌شود، محدودیت دسترسی پیامک گوگل‌پلی شامل آن نمی‌شود. اگر شماره فرستنده را نمی‌دانید، یک پیامک بانکی را باز کنید و شماره فرستنده را کپی کنید.

## 💾 پشتیبان‌گیری بین دستگاه‌ها

تنظیمات → پشتیبان‌گیری:
- **ساخت پشتیبان**: یک فایل JSON با تمام داده‌ها (اختیاری: شامل عکس‌ها)
- **بازگردانی**: همان فایل را در هر دستگاه/پلتفرم دیگری وارد کنید — «جایگزینی کامل» یا «ادغام»

## 🏗 معماری

- Flutter + Dart، رابط کاربری کاملاً راست‌به‌چپ و فارسی با فونت وزیرمتن
- ذخیره‌سازی محلی با Hive (بدون نیاز به سرور)
- گیرنده پیامک بومی اندروید با Kotlin (MethodChannel)
- CI/CD با GitHub Actions برای هر ۵ پلتفرم
