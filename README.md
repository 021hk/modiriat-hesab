# حساب‌یار — نرم‌افزار مدیریت حساب 💰

نرم‌افزار مدیریت موجودی، هزینه، بدهکاران و طلبکاران با اتصال به پیامک‌های بانکی.
آنلاین و تحت وب — روی اندروید، ویندوز، مک و لینوکس به‌صورت اپلیکیشن قابل نصب است (PWA).

## ✨ امکانات

- **داشبورد مالی**: موجودی کل، درآمد و هزینه ماه، مقایسه با ماه قبل، نمودار هزینه به تفکیک دسته
- **دسته‌بندی هزینه و درآمد**: ساخت، ویرایش و حذف دسته‌ها با رنگ‌بندی دلخواه
- **تراکنش‌ها**: ثبت واریز/برداشت با فیلد «بابت فلان» برای یادداشت دلیل هر برداشت، جستجو و فیلتر
- **بدهکاران و طلبکاران**: ثبت طلب از دیگران یا بدهی خودتان، پرداخت جزئی، تسویه کامل
- **عکس رسید**: افزودن چند عکس رسید به هر بدهی (فشرده‌سازی خودکار تصویر در مرورگر)
- **چند حساب بانکی**: مدیریت هم‌زمان چند حساب با محاسبه خودکار موجودی (موجودی اولیه + واریز − برداشت)
- **تشخیص خودکار پیامک بانک**: پیامک واریز/برداشت را بچسبانید؛ نوع، مبلغ و نام بانک به‌طور خودکار تشخیص داده می‌شود و با یک تأیید به تراکنش تبدیل می‌شود
- **پشتیبان‌گیری قابل انتقال**: کل داده‌ها (شامل عکس‌ها) در یک فایل JSON — قابل بازیابی روی هر دستگاه و هر نسخه
- **آنلاین و تحت وب**: داده‌ها روی سرور ذخیره می‌شوند و از هر دستگاهی با همان آدرس در دسترس‌اند
- **نصب به‌عنوان اپلیکیشن (PWA)**: روی اندروید (Chrome → Add to Home Screen)، ویندوز/مک/لینوکس (Chrome/Edge → Install App)

## 🛠 تکنولوژی

- Next.js 16 + TypeScript + Tailwind CSS 4
- shadcn/ui + Radix UI (رابط فارسی راست‌به‌چپ با فونت وزیرمتن)
- Prisma + SQLite
- TanStack Query
- PWA (Service Worker + Manifest)

## 🚀 اجرا

```bash
# نصب وابستگی‌ها
bun install

# تنظیم دیتابیس
echo 'DATABASE_URL="file:./db/custom.db"' > .env
bun run db:push

# اجرای محیط توسعه
bun run dev
```

سپس `http://localhost:3000` را باز کنید.

## 📱 نصب روی دستگاه‌ها

| پلتفرم | روش نصب |
|--------|---------|
| اندروید | Chrome → منو → «افزودن به صفحه اصلی» |
| ویندوز | Chrome/Edge → منو → «نصب برنامه» |
| مک | Chrome → منو → «Install» |
| لینوکس | Chrome → منو → «Install» |

> برای نسخه‌های نیتیو (APK اندروید یا DMG/Mac، AppImage/Linux، EXE/Windows) می‌توان همین پروژه را با **Tauri** (دسکتاپ) یا **Capacitor** (اندروید) بسته‌بندی کرد — ساختار کد آماده است.

## 💾 پشتیبان‌گیری

تب «پشتیبان» → دانلود فایل پشتیبان (JSON). برای انتقال به دستگاه دیگر، همان فایل را در تب «پشتیبان» انتخاب و بازیابی کنید. عکس رسیدها هم داخل فایل ذخیره می‌شوند.

## 📡 اتصال پیامک بانک

1. تب «حساب و پیامک» → حساب‌های بانکی‌تان را بسازید
2. پیامک واریز/برداشت بانک را کپی کنید
3. در کادر «ورود پیامک بانکی» بچسبانید → «پیش‌نمایش تشخیص»
4. «افزودن به صف» → «ثبت تراکنش»

فرمت‌های رایج بانک‌های ایران (ملت، صادرات، ملی، تجارت، پارسیان و…) پشتیبانی می‌شوند. در نسخه اندروید می‌توان با مجوز `RECEIVE_SMS` خواندن پیامک را کاملاً خودکار کرد.
